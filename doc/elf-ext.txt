
动态表增加：

1. EXPORT 数据
#define DT_EXPSYM        38
#define DT_EXPCOUNT      39

每一项数据定义如下：
typedef {
    Addr  addr;       // 符号在字符串表中的偏移
	Addr  value;      // 符号的值
}Elf64_Export;

2. IMPORT 数据
#define DT_IMPSYM        40
#define DT_IMPCOUNT      41

typedef {
    Addr      addr;      // 指向符号(NULL结尾的字符串)的地址
	uint32_t  hint;      // 该符号最有可能是so中导出的符号的第几个
    uint16_t  module;    // 从哪个so导入，第几个 DT_NEEDED (从0开始算起)
	uint8_t   type;      // 1: 函数  2: 数据
	uint8_t   reserve;
} Elf64_Import;

3. 导入地址表
#define DT_IMPADDR        31

导入地址表的条目数量与DT_IMPCOUNT指定相同，与DT_IMPSYM 一一对应。
加载器会把对用导入的符号的地址填充到对应的位置。

4. 相对重定位
#define DT_RELR2          42

数据格式为 “页数据头+重定位数据” 不停重复，直到某个页数据头全0结束

页数据,每一页为16KB,

页数据头为64位（32位ELF为32bit），低14位表示重定位的个数，高位部分表示页地址


每一项16bit, 低14bit代表重定位地址，高2bit代表定位类型：
0: 32bit 地址
1: 多条指令组成32bit地址
2: 64bit 地址
3: 多条指令组成64bit地址

以最后一个页数据头全部为0结尾。
